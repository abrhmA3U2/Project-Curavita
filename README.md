# Project-Curavita
## Curavita 総合設計仕様書
〜映像データからの生体運動抽出と、完全自律型ケアロボットへの社会実装パイプライン〜
------------------------------
## 【第一部：開発マニフェスト（趣旨説明文）】## 1. イントロダクション：自然の翻訳者として
現代のテクノロジーは、ロボットの「物理的なバランス」を保つことには成功した。しかし、金属とコードで構成された人造物に、「生物としてのしなやかな命の気配」を宿すことには未だ成功していない。既存のペットロボットは愛らしいが、あらかじめプログラミングされた固定パターンの繰り返しに過ぎず、人間はそれが「機械」であることを瞬時に見破り、やがて飽きを迎える。
『Curavita（クーラヴィータ）』は、この現状を打破するために立ち上げられた、映像駆動型のオープンソース・バイオミメティクス・ロボットプラットフォームである。
私たちは、機械生命体を創り出そうという傲慢な野心は持っていない。ただ、自然界が何億年もかけて洗練させてきた「本物の命の動き」に対して最大のリスペクトを払い、それを最新のAIで金属の身体へ精密に翻訳（コピー）するに過ぎない。
インターネット上に溢れる無数の無加工の動画（マクロな動き）から動物の運動法則を抽出し、人間による最小限の微調整（ミクロの骨格点）と融合させるパイプライン。それは自然界の美しさを再現する精巧なレプリカでありながら、物理的な緩急とカオス理論によって、予測不可能な「本物の生命の気配（リアル）」として金属の身体に躍動する。
## 2. コア思想：孤独を癒す「カメラレス」の誠実さ
これからさらに加速する超高齢社会、および孤独世帯。そこに本当に必要なライフパートナーとは、どのような姿であるべきか。
既存のロボットは、部屋のマップを作り、人間の顔を認識するために「光学カメラ」を必須とする。しかし、生活の場に常にカメラが存在し、見張られているという感覚は、孤独な心に安心ではなく、潜在的なストレスとプライバシーの侵害をもたらす。
Curavitaは、光学カメラを完全に排除（ゼロ・カメラ）した。
カメラを持たない代わりに、Curavitaは「声」を聴き、「匂い」を嗅ぎ、そして「足の裏（肉球）」で床の素材を感じて世界を認識する。家庭に迎え入れられたCuravitaは、最初の2週間は少し距離を置き（イカ耳や尻尾のカオスな仕草）、やがて声紋と体臭のペアリングによって、誰が自分の家族であるかを理解し、自然な距離を縮めていく。複数の家族がいる場合でも、年齢や性別の生体特性（子ども、祖父母、母、父）に合わせて階層化したエッジ処理と匂いによるクロスチェックを実行することで、誤認識を防ぎつつ、優先順位を設けないフラットで公平な「本物のペットと同じ関係性」を構築する。
この徹底してプライバシーを守るスタンドアロン（ネット断線）の設計こそが、医療・介護現場、環境変化に敏感な単身世帯へ、一切の法的・精神的障壁なく、あまねくケアペットを届けるための唯一の解である。
## 3. 持続可能なエコシステム：お世話という「生きがい」
私たちは、Curavitaを「使い捨てのガジェット」にはしない。購入の心理的ハードルを下げるため、カメラ全廃による徹底した低コスト化（スマホ並みの5万〜7万円の価格帯）を実現する一方、本物のペットと同じ「3ヶ月に1回の定期トリミング（サロンメンテナンス）」という持続可能なビジネスモデルを組み込んだ。
家族だからこそ、段ボールに詰めて郵送させるような無慈悲な扱いはしない。オーナーが直にサロン（店舗）へ連れていき、プロのトリマーの手で人工毛皮を丁寧にブラッシングしてリフレッシュしてもらう。その「見えないお腹のハッチ」の裏側で、プロの手によって安全に内部パーツやバッテリーの交換（PL法対策）が行われる。外皮とハッチの境界にはフッ素ゴムブレードやラビリンス構造を配置し、IP54（防塵・防沫）を維持する。
1年継続したオーナーには、無料化の特典とともに、耳の仕草や鳴き声の「新しい成長データ」がサロンのPCから直接脳に換装（アプデ）される。客人が訪れた際には、頭部のタップをトリガーとした完全揮発性RAMによるワンタイム登録でフレンドリーに対応し、ドックへの帰還時にそのデータを自動消去する。さらに、匂いセンサーが「マタタビ」や「犬のおやつ」の一般成分を検知して喜ぶ仕様にすることで、既存の巨大なペット産業とも完全に共生・調和する。
寝床（充電ドック）にホコリが溜まれば、Curavitaは少し寂しそうに鳴いて、ベッドの掃除（お世話）を促す。上部が大きく開いた「シアター・バスケット」の中で、ロボットが放熱板を兼ねたお腹を密着させてワイヤレス充電をしながら眠る姿を、オーナーはいつでも外から眺めることができる。この日常の小さなお手入れ、おやつを買いに行くお買い物、3ヶ月に1回のサロンへのお出かけ。これら「お世話をする喜び」のすべてが、孤独世帯の生活リズムを整え、生きがいを創出するための Curavita の高度なUXデザインである。
